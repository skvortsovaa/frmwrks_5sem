Таблица 7.3 PR11_Django_Forms.pdf, страницы 103–106. Примечание на странице 102 разрешает адаптацию к индивидуальному проекту. Аналог Booking — InspectionPlan, план проверки помещения. Report и Reading остаются неизменяемой историей измерений.

### 14. POST и CSRF

Продемонстрируйте защиту операций изменения данных

plan_views.py → @require_POST; plan_form.html и plan_list.html → {% csrf_token %}.

- Откройте активный план N. В адресной строке перейдите на /inspections/N/cancel/: это GET, статус не изменяется.
- Вернитесь в список и отмените план кнопкой. В Network браузера покажите метод POST и перенаправление. Автотест отдельно проверяет запросы без CSRF.

GET отмены возвращает 405; штатная POST-форма отменяет план. Запрос без действующего CSRF-токена получает 403.
